# inbox-triage workflows

Step-by-step runs for the triage skill. The contract they operate under is
`../SKILL.md`.

- `morning-sweep.md` -- the daily run, start to finish.
- `daily-digest.md` -- the five-section digest, including what it was unsure about.
- `undo-filing.md` -- reversing one action or a whole sweep, mechanically from the ledger.
- `taxonomy-change.md` -- adding, renaming, or removing a folder without breaking history.
