# voice-profile

Builds a description of how the owner writes, from sent mail the owner selected
-- and quotes not one word of it. `enhanced` tier only.

- `SKILL.md` -- the contract: the selected-sources rule, the no-quoting rule, the
  review gate, and the refusals.
- `workflows/` -- selection, building, the owner's review pass, and rebuilding.

The output is a file the owner can open, edit, and delete. Nothing drafts until
they have read it and marked it reviewed.
