# voice-profile workflows

Step-by-step runs for the voice skill. The contract they operate under is
`../SKILL.md`.

- `selection-interview.md` -- what feeds each voice, and what is excluded.
- `build-profile.md` -- reading the selected sample and writing the style document.
- `review-and-approve.md` -- the owner's read-and-redact pass, which is the gate.
- `update-voice.md` -- rebuilding after drift, keeping the previous version.
