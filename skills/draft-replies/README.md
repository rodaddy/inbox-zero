# draft-replies

Writes first-draft replies into the owner's own Drafts folder, so they start
from something instead of a blank box. `enhanced` tier only.

- `SKILL.md` -- the contract: voice comes from the connector's rule and not from
  the AI, untrusted-input hardening, recipient limits, and the refusals.
- `workflows/` -- one reply, a capped batch, and the missing-fact gate.

A draft is not a sent message. The owner opens it, changes what they want, and
presses send. It is addressed only to people already on the thread, never a new
recipient, and it refuses to invent a price, a date, or a decision.
