# draft-replies workflows

Step-by-step runs for the drafting skill. The contract they operate under is
`../SKILL.md`.

- `draft-one-reply.md` -- a single thread, start to finish.
- `draft-batch.md` -- a capped batch, with the list of what it skipped and why.
- `missing-fact-gate.md` -- stop-and-ask when a fact is missing, plus the
  hedge-answer check that refuses a range.
