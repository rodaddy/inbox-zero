# docs

Reference documentation that ships with the kit (`docs` is on the `ship` list in
`scripts/packaging/tiers.json`).

- `google-external-client-setup.md` -- standing up the Google OAuth client used
  by the Gmail provider.
- `what-leaves-the-machine.md` -- the egress statement: which bytes go where.
- `security/write-paths.md` -- the mutation statement: every write the connector
  can perform, in the mailbox, on disk, in the keychain, and on the wire.
- `STANDARDS-COMPLIANCE.md` -- how this app satisfies the Development standards,
  claim by claim, with the command that proves each one.
